# bizon-slots

Сервис динамических слотов автовебинара для бота в Сейлботе (MAX).
Слоты по МСК: 14:00, 16:00, 19:00, 21:00 (меняются в env `SLOTS`).

## Эндпоинты
- `GET /slots` — актуальные слоты. Плоские поля для переменных Сейлбота:
  `has_today`, `today_count`, `t1..t4` (сегодня), `m1..m4` (завтра).
- `GET /resolve?text=<текст кнопки>` — проверка выбранного слота перед регистрацией:
  `valid`, `date`, `time`, `ts`, `time_utc` (для Бизона), `remind_60`, `delay_60`, `delay_7` (секунды для отложенных сообщений).
- `GET /health`

## Деплой
Push в `main` → тесты → копирование на VDS в `/opt/bizon-slots` → venv + systemd-сервис `bizon-slots`.
Секреты репозитория: `VDS_HOST`, `VDS_USER`, `VDS_PASSWORD`. Порт 8088.
