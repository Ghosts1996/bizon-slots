# bizon-slots

Сервис динамических слотов автовебинара для бота в Сейлботе (MAX).
Слоты по МСК: 14:00, 16:00, 19:00, 21:00 (меняются в env `SLOTS`).

## Эндпоинты
- `GET /slots` - актуальные слоты. Плоские поля для переменных Сейлбота:
  `has_today`, `today_count`, `t1..t4` (сегодня), `m1..m4` (завтра).
- `GET /resolve?text=<текст кнопки>` - проверка выбранного слота перед регистрацией:
  `valid`, `date`, `time`, `ts`, `time_utc` (для Бизона), `remind_60`, `delay_60`, `delay_7` (секунды для отложенных сообщений).
- `GET /health`

## Деплой
Push в `main` → тесты → копирование на VDS в `/opt/bizon-slots` → venv + systemd-сервис `bizon-slots`.
Секреты репозитория: `VDS_HOST`, `VDS_USER`, `VDS_PASSWORD`. Порт 8088.

## Схема в Сейлботе (проект 803129)

Все блоки автовебинара имеют префикс «АВ:» и лежат на основном листе отдельной сеткой ниже старой воронки.
Правило: блок, который ходит в API, сам ничего не пишет (`#{none}`), а сообщение отправляет следующий блок
по стрелке с условием на переменную. Так сообщение не уходит пустым, если сервер ответил «не нужно».

| Блок | API | Дальше |
|---|---|---|
| Приветствие (`/start`) | `/slots?client_id=` (b1..b4, отметка старта) | через 30 мин → «АВ: дожим проверка» |
| АВ: дожим проверка / (завтра) | `/nudge?step=30m` / `step=day` → `nudge_ok` | `nudge_ok == 1` → «АВ: дожим» |
| АВ: выбор времени (текстом спросили про время) | `/slots` | — |
| АВ: завтра (кнопка «Все сеансы на завтра») | `/slots` (m1..m4) | через 60 мин → «АВ: дожим проверка (завтра)» |
| АВ: запись (нажата кнопка со временем) | `/resolve` → `valid`, `msg`, задержки | `valid == 1` → «запись — подтверждение», иначе → «время недоступно» |
| АВ: запись — подтверждение | — | через `delay_60` → «АВ: за час — проверка» |
| АВ: за час — проверка | `/due?step=hour` → `hour_ok`, `hour_text` | `hour_ok == 1` → «АВ: за час»; через `delay_gap` → «АВ: ссылка — проверка» |
| АВ: ссылка — проверка | `/due?step=link` → `link_ok`, `link_text` | `link_ok == 1` → «АВ: ссылка»; через 95 мин → «АВ: проверка» |
| АВ: проверка | `/visited` → `visited`, `again`, `record` | «пришёл» / «не пришёл» / «видео-запись.» |
| АВ: видео-запись. | `/due?step=record` → `ok` | `ok == 1` → «запись — сообщение» |

Сервер сам отбрасывает устаревшие и повторные шаги (перезапись на другое время, повторный /start),
поэтому таймеры Сейлбота отменять не нужно.
